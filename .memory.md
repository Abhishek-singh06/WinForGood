## 7. IMPORTANT ARCHITECTURE DECISIONS

- **Next.js 15 App Router & Server Components:** Primary layout authorization and data fetching execute on the server.
- **Pure Validation Modules:** Client/server shared pure validation functions live in separate non-`"use server"` files (`validation.ts`) to avoid Next.js Server Action compiler constraints.
- **Multi-Layer RBAC Defense:** Edge Middleware provides fast redirect gating; Server Layouts independently query database roles to prevent spoofing or middleware bypass.
- **Service Role Isolation:** `src/lib/supabase/admin.ts` enforces `import "server-only"` to prevent secret leakage to client bundles.
- **Atomic Database Triggers for Concurrency:** Rolling 5 score retention is enforced via PostgreSQL `AFTER INSERT OR UPDATE` trigger on `scores`, guaranteeing database-level consistency regardless of concurrent requests.
