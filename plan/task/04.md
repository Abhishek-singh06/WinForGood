# Task 04: Random & Algorithmic Draw Execution Strategies

## Contexto
Implement both PRD draw modes: Random draw and Algorithmic weighted draw according to Decision #2 (BR-048).

## Subtareas
- [x] Create `src/lib/draws/engine.ts` implementing `RandomDrawStrategy`:
  - 5 distinct numbers sampled uniformly from 1 to 45 without replacement.
  - Cryptographically secure pseudo-random generation with seed override option for reproducible testing.
- [x] Implement `AlgorithmicDrawStrategy`:
  - Compute frequency distribution $f(n)$ across active participant tickets in the cycle.
  - Laplace smoothing $W(n) = f(n) + 1$ for all $n \in \{1..45\}$.
  - Sequential weighted sampling without replacement across 5 steps, dynamically renormalizing remaining weights.
  - Seed support for deterministic auditing/testing.
