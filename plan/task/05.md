# Task 05: Prize Pool Calculator, Rollover & Charity Disposition Engine

## Contexto
Implement prize pool accounting conforming to TA-001 (30%), TA-003 (GBP), TA-004 (£10/1000p), TA-005 (£100/10000p), PRD § 07 (40%/35%/25% split), and TA-006 (Model B Charity Disposition for lower-tier unclaimed funds).

## Subtareas
- [x] Create `src/lib/draws/pool.ts` implementing `IPrizePoolCalculator` and full prize accounting:
  - Monthly MER = 1000p, Yearly MER = Math.floor(10000 / 12) = 833p.
  - Compute gross new pool = 30% of aggregate MER.
  - Calculate tier allocations: Tier 5 = floor(Gross * 0.40) + rollover_in; Tier 4 = floor(Gross * 0.35); Tier 3 = floor(Gross * 0.25).
  - Remainder cents preserved and tracked.
  - Unclaimed Tier 5 -> rollover to next month.
  - Unclaimed Tier 3 & Tier 4 -> disposition = 'CHARITY' (TA-006).
  - Multi-winner split: floor(allocation / winner_count), remainder preserved in `remainder_amount`.
