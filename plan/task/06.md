# Task 06: Production Server Actions (Simulation & Publication)

## Contexto
Update server actions in `src/lib/draws/actions.ts` to coordinate real database state changes during the draw lifecycle: `draft` -> `simulated` -> `published`.

## Subtareas
- [x] Implement robust `stageDrawSimulationAction`:
  - Fetch active subscribers and their rolling scores.
  - Generate tickets via `DirectScoreToTicketMapper` for eligible users via `DynamicPartialEligibilityResolver`.
  - Execute winning numbers generation (Random or Algorithmic).
  - Calculate matches for every participant entry.
  - Calculate gross pool, tier allocations, winners, rollover, and charity disposition.
  - Persist snapshot into `draw_entries`, `draw_tier_allocations`, and update `draws` state to `simulated`.
- [x] Implement `publishDrawAction`:
  - Validate draw is in `simulated` state.
  - Insert winners into `winners` table with `match_tier`, `prize_amount`, `verification_status: 'pending'`, `payout_status: 'pending'`.
  - Update `draws` state to `published`, freezing `published_at` and final `jackpot_rollover_out`.
- [x] Implement helper queries to retrieve complete draw details, allocations, and winners.
